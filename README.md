# 虚空花园 · Void Garden

一个可直接在浏览器试玩的轻量生存肉鸽原型。双击 `index.html`，或用任意本地 Web 服务器打开即可游玩；手机、平板、电脑通用，支持添加到主屏幕离线游玩。

## 玩法

- WASD / 方向键移动，自动瞄准并施放法术
- 三个主动技能：空格 / Shift 冲刺（短暂无敌）、E / J 绽放（范围爆发并清弹幕）、Q / K 护盾（抵挡伤害）
- 三名花灵开局：星芽（清场）、荆棘蔓（爆发）、露珠（生存）
- 五件初始法器：星辉法杖、蔷薇短弓、月刃轮、荆棘之鞭、星尘漩涡
- 6 级一段进化，12 级二段进化，每件法器各有两次蜕变
- 击败虚空生物、吸收星尘（经验）升级；每次升级从三项强化中三选一
- 18 项可叠加技能：穿透、爆裂、弹速、尺寸、暴击、环绕月种、雷霆绽放、生命回复等
- 六种敌人（普通 / 疾跑 / 重装 / 分裂 / 炮台 / 治疗），清完一波才出下一波，同屏数量有上限
- 三种首领轮番出现，登场为 1v1（清空杂兵），各有独特攻击方式
- 清空一波或首领后掉落「生命饰品」，拾取回复生命
- 难度选择：简单 / 普通 / 困难 / 无尽
- 受击有短暂无敌帧；首领出招前有预警；困难 / 无尽会随机出现精英怪
- 战斗反馈：屏幕震动（可关闭）、伤害数字、击杀特效、护盾条
- 按 `P` 暂停：暂停菜单可「继续 / 重玩 / 设置 / 返回主界面」
- 支持手柄左摇杆移动、Start 暂停、A 绽放、B 冲刺、X 护盾
- 手机虚拟摇杆与「冲刺 / 绽放 / 护盾 / 暂停 / 全屏」按钮，支持手机全屏游玩

## 金币商城

- 游玩结算获得 **金币**：净化数量、存活时长与击败的首领都会换算，困难 / 无尽模式有加成
- 用金币解锁新花灵（荆棘蔓、露珠）
- 「商城」分三栏，均可用金币升级或购买：
  - 装备：生命、伤害、移速、冷却、暴击、拾取范围（最高 12 级，满级显示 MAX）
  - 技能：冲刺、绽放、护盾的冷却 / 强度（最高 12 级，满级显示 MAX）
  - 道具：复活花、生命泉水、经验菌（下一局自动生效）

## 成就与每日挑战

- 主页「成就」可查看进度；解锁成就额外奖励金币
- 「每日挑战」按日期固定花灵与法器组合，并记录当日最佳存活

## 设置

- 音量调节、音乐开关、屏幕震动开关、语言切换（中文 / English）
- 重置全部进度

## 数据

- 最佳存活、金币、解锁、装备/技能等级、道具、成就、设置都保存在浏览器 `localStorage` 中
